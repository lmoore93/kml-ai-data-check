KML AI Data Check (AU) hosted PWA (client-side)
Your KML/KMZ file is processed locally in your browser. This tool calls public data services (Overpass/Open‑Meteo) using ring bounding boxes. Decision support only: verify airspace/NOTAM/obstacles via approved sources.

Upload + configure

Example: [1,3,5] creates 0–1, 1–3, 3–5 km rings around the uploaded geometry.
For privacy, the app sends only derived metrics/facts (not the raw KML file) to Gemini.
If you don’t remember the key, you’ll be prompted each time. Never share your key publicly.
Expected: band 0 values = people/km².
